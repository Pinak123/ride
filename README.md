Vride 🚲
Vride is a web-based platform developed specifically for students of VIT to easily rent bicycles on campus. The platform aims to promote sustainable transportation, save time, and enhance campus mobility through a smooth, student-friendly interface.

🔍 Features
🧾 User registration and login (student authentication)

🚲 View available cycles in real-time

📍 Cycle station locator

📅 Booking and rental scheduling

💸 Simple payment integration (demo version)

📊 Admin dashboard to manage rentals and availability

Frontend: HTML, CSS, JavaScript, React.js

Backend: Node.js, Express.js (or mention your stack if different)

Database: MongoDB / Firebase (mention whichever you used)

🎯 Purpose
Designed to simplify the process of renting bicycles within VIT, Vride empowers students to move faster and smarter while contributing to an eco-friendly campus environment.
